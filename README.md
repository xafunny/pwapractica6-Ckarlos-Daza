# Panadería La Espiga

Sistema de gestión de una panadería. Proyecto final de Programación Web Avanzada (Ejercicio 33).

**Integrante:** Ckarlos Daza

## Tecnologías

HTML, CSS, Bootstrap 5, JavaScript, PHP 8 (sin frameworks) y MySQL.

## Instalación

1. Copiar el proyecto en `htdocs` (XAMPP) o `www` (Laragon).
2. En phpMyAdmin crear la base de datos `panaderia` e importar `panaderia.sql`.
3. Abrir el proyecto en el navegador desde `http://localhost/`.
